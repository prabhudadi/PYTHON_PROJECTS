# 🐍 Prabhu's Python Projects

## 📌 About the Project

Welcome to **Prabhu's Python Projects**! This repository contains 20 beginner-friendly Python projects created to practice programming fundamentals and build practical coding skills.

The projects cover calculations, games, converters, student tools, and everyday utilities using Python.

## 🛠️ Technologies Used

- **Python 3**
- Built-in Python modules:
  - `random`
  - `time`
  - `datetime`
- External library:
  - `qrcode`

## ⚙️ Requirements

- Python 3 installed on your computer
- A code editor such as Visual Studio Code
- The `qrcode` library for the QR Code Generator project

Install the required library using:

```bash
pip install "qrcode[pil]"
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the Python file:

   ```bash
   python Prabhu_Projects.py
   ```

**Note:** The file contains multiple projects, and the code executes sequentially. Some projects require user input as they run.
